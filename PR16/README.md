## Как запустить

Нужен установленный Node.js. Откройте терминал в папке `PR16`:

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Для автоматических тестов используйте `npm test`.

Данные пользователя подгружаются из JSONPlaceholder, поэтому для этой демонстрации нужен интернет. При ошибке загрузки появится сообщение.

**Не загружайте `node_modules` на GitHub.** Папка зависимостей устанавливается через `npm install` и исключена из Git.

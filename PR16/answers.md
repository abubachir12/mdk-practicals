# Ответы на вопросы к ПР16

1. **Разница между useState и useReducer.** `useState` подходит для простых значений: счетчика, текста, переключателя. `useReducer` удобен, если действий и правил изменения состояния много, например для корзины или секундомера. Он позволяет вынести переходы состояния в отдельную функцию.

2. **Массив зависимостей useEffect.** При `[]` эффект выполняется после монтирования (в режиме разработки StrictMode возможен дополнительный запуск для проверки очистки). При `[value]` он повторяется после изменения `value`. Если не указать массив, эффект будет выполняться после каждого рендера.

3. **Stale closure.** Это ситуация, когда обработчик или таймер использует старое значение состояния из замыкания. Например, вместо `setCount(count + 1)` в интервале надежнее писать `setCount(prev => prev + 1)`.

4. **useCallback и useMemo.** `useMemo` запоминает результат вычисления, а `useCallback` сохраняет ссылку на функцию между рендерами. Они полезны при реально дорогих вычислениях или когда нужна стабильная ссылка. Во всех компонентах подряд использовать их не стоит: это тоже дополнительные затраты и усложнение.

5. **useRef и useState.** `useState` вызывает рендер при изменении значения. `useRef` хранит изменяемое значение без нового рендера. `useRef` полезен для фокуса на input, таймеров, хранения предыдущего значения и ссылок на DOM.

6. **Правила хуков.** Хуки вызывают только в React-компонентах или других хуках, всегда на верхнем уровне, не внутри условий, циклов и вложенных функций. Тогда React сможет сопоставлять вызовы хуков в одинаковом порядке при каждом рендере.

7. **Создание кастомного хука.** Это функция с названием, начинающимся с `use`, например `useDebounce`. В нее выносится повторяющаяся логика на базе других хуков. Важно правильно задавать зависимости, очищать таймеры и подписки, обрабатывать ошибки.

8. **Преимущества useContext.** Контекст позволяет получить общее значение, например тему оформления, без передачи `props` через много промежуточных компонентов. Это удобно для часто используемых глобальных настроек, но не заменяет любое локальное состояние.

9. **Асинхронные операции в кастомном хуке.** Обычно используют `useEffect`, `fetch`, а состояние загрузки и ошибок ведут через `useState`. При размонтировании или смене URL нужно отменять старый запрос с помощью `AbortController`, чтобы устаревший ответ не перезаписал новый.

10. **Отладка хуков.** Можно проверять состояние в React DevTools, использовать `console.log`, вкладку Network для запросов и инструменты браузера для установки точек останова. Еще помогают тесты для редьюсеров и компонентов, а также ESLint с правилами React Hooks.

# Ответы на вопросы к ПР5

1. В чем главное отличие CSS Grid от Flexbox?
Flexbox — одномерный (работает либо по строке, либо по колонке). Он хорош для компонентов, выравнивания кнопок или навигации. А CSS Grid — двумерный, он управляет сразу строками и столбцами одновременно. Поэтому Grid идеален для создания общего каркаса сайта (шапка, сайдбар, контент, подвал).

2. Что такое единица fr в гридах?
fr (fractional unit) — это доля свободного пространства в контейнере. Например, grid-template-columns: 1fr 2fr делит контейнер на 3 части: первая колонка заберет одну часть, а вторая — две оставшиеся.

3. Чем удобна связка repeat(auto-fit, minmax(...))?
Это самый популярный трюк в гридах для создания адаптивной галереи вообще без медиа-запросов. Браузер сам вычисляет, сколько колонок минимальной ширины (например, 200px) помещается на экран, и автоматически переносит лишние карточки на новую строку.

4. Зачем нужно свойство grid-template-areas?
Оно позволяет буквально «нарисовать» макет страницы словами в виде понятной текстовой карты. Это делает CSS наглядным: сразу видно, где шапка, где сайдбар, и легко менять их расположение в одну строчку.

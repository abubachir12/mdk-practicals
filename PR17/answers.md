# Ответы на вопросы к ПР17

1. **Разница между управляемыми и неуправляемыми компонентами.** В управляемой форме значение поля хранится в состоянии React, передается через `value` или `checked` и обновляется через `onChange`. В неуправляемой форме значение находится в самом DOM, а для получения можно использовать `useRef`.

2. **Когда использовать каждый подход?** Управляемые поля удобны, если нужно сразу проверять ввод, показывать ошибки и управлять полями из кода. Неуправляемые проще, когда форма небольшая и достаточно получить значения только при отправке.

3. **Обработка событий в формах React.** Используют `onChange` для изменений, `onSubmit` для отправки, иногда `onBlur` для проверки после ухода из поля и `onFocus` для фокуса. Обработчики получают объект события.

4. **Один обработчик для нескольких полей.** Полям можно задать `name`, затем брать `event.target.name` и `event.target.value`. Для checkbox нужно использовать `event.target.checked`. Состояние обновляется так: `setForm(prev => ({ ...prev, [name]: value }))`.

5. **Подходы к валидации.** Есть встроенная проверка браузера (`required`, `minLength`, `type="email"`), самостоятельная проверка JavaScript и специальные библиотеки. В этой работе использована функция `validateRegistration`, которая собирает ошибки для всех обязательных полей.

6. **Как предотвратить перезагрузку страницы?** В `onSubmit` нужно вызвать `event.preventDefault()`. После этого данные можно проверить и обработать без стандартной отправки формы.

7. **Что такое lifting state up в формах?** Если несколько компонентов должны работать с одними данными, состояние поднимают в ближайший общий родитель. Родитель передает дочерним компонентам значения и обработчики через `props`. Так, например, можно сделать общую форму с несколькими секциями.

# Ответы на вопросы к ПР10

1. **Function Declaration и Function Expression при hoisting.**  
Function Declaration поднимается целиком, поэтому функцию можно вызвать до строки объявления. У Function Expression поднимается только переменная, а значение-функция присваивается во время выполнения.

2. **Rest parameters и arguments.**  
Rest parameters `...args` создают настоящий массив и явно показывают, какие аргументы собираются. `arguments` - специальный псевдомассив, доступный в обычных функциях, но не в стрелочных функциях.

3. **Что такое замыкание?**  
Замыкание возникает, когда внутренняя функция продолжает иметь доступ к переменным внешней функции даже после завершения внешней функции. Это связано с лексической областью видимости.

4. **Рекурсия и итерация.**  
Рекурсия удобна для задач с естественной древовидной структурой и рекурсивным определением. Итерация обычно экономнее по памяти и не рискует переполнением стека на большой глубине.

5. **Функции высшего порядка.**  
Это функции, которые принимают другие функции как аргументы или возвращают функции. Примеры встроенных методов: `map`, `filter`, `reduce`, `forEach`, `some`, `every`.

6. **Что такое каррирование?**  
Каррирование преобразует функцию с несколькими аргументами в цепочку функций, каждая из которых принимает часть аргументов. Это удобно для частичного применения и повторного использования настроенных функций.

7. **Как работает мемоизация?**  
Результат вызова сохраняется в кэше по аргументам. При повторном вызове с теми же аргументами функция возвращает готовое значение. Особенно полезно для дорогих и повторяющихся вычислений.

8. **Debounce и throttle.**  
Debounce выполняет функцию после паузы в серии событий. Throttle разрешает выполнение не чаще заданного интервала. Debounce удобен для поиска по вводу, throttle - для scroll, resize и mousemove.

9. **Функции-генераторы.**  
Генератор объявляется через `function*` и может приостанавливать выполнение с помощью `yield`. Обычная функция выполняется до конца и возвращает одно итоговое значение.

10. **Какие принципы функционального программирования применены?**  
Использованы функции как значения, функции высшего порядка, композиция, каррирование, замыкания, минимизация побочных эффектов и возврат новых значений вместо изменения исходных данных.

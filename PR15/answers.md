# Ответы на вопросы к ПР15

1. **В чем разница между функциональными и классовыми компонентами в React? Когда следует использовать каждый тип?**  
Функциональный компонент является обычной JavaScript-функцией, которая возвращает JSX. Для состояния и жизненного цикла в нем используются хуки. Классовый компонент наследуется от `React.Component`, имеет метод `render()` и работает с `this.state` и методами жизненного цикла. В новых приложениях чаще используют функциональные компоненты, но классовые компоненты важно понимать для существующих проектов.

2. **Что такое props и state? Как они отличаются и какие правила их использования?**  
`props` передаются компоненту снаружи и используются как входные данные. Сам компонент не должен изменять полученные props. `state` хранит внутреннее изменяемое состояние компонента. При изменении state React выполняет повторный рендер компонента.

3. **Как работает lifting state up и когда это необходимо?**  
Если нескольким дочерним компонентам нужны одни и те же данные, состояние переносят в их ближайший общий родительский компонент. Родитель хранит state и передает данные и функции изменения через props. Это позволяет синхронизировать дочерние компоненты.

4. **Какие методы жизненного цикла классовых компонентов вы знаете?**  
`componentDidMount()` вызывается после появления компонента в DOM и подходит для запросов и подписок. `componentDidUpdate()` вызывается после обновления props или state. `componentWillUnmount()` выполняется перед удалением компонента и используется для очистки таймеров и обработчиков событий.

5. **Как работают useState и useEffect? Какие правила использования хуков существуют?**  
`useState` добавляет состояние функциональному компоненту. `useEffect` выполняет побочные действия после рендера и может возвращать функцию очистки. Хуки нужно вызывать только на верхнем уровне React-компонента или собственного хука, а не внутри условий и циклов.

6. **Что такое keys в React и почему они важны при рендеринге списков?**  
`key` является уникальным идентификатором элемента списка. По ключам React понимает, какие элементы были добавлены, удалены или изменены. В качестве ключа лучше использовать стабильный уникальный id.

7. **Как обрабатывать события в React и чем это отличается от нативного JavaScript?**  
Обработчик передается в JSX как функция, например `onClick={handleClick}`. Названия событий записываются в camelCase. React передает объект события обработчику и сам управляет привязкой событий.

8. **Что такое управляемые и неуправляемые компоненты?**  
Управляемый элемент формы получает значение из state и меняет его через `onChange`. Неуправляемый элемент хранит значение непосредственно в DOM, а получить его можно, например, через `ref`.

9. **Как работает Context в React и когда его следует использовать?**  
Context позволяет передавать данные вложенным компонентам без передачи props через каждый уровень. Обычно создается Context, Provider передает значение, а дочерние компоненты получают его через `useContext`.

10. **Какие преимущества предоставляют кастомные хуки и как создавать собственные хуки?**  
Кастомный хук позволяет вынести повторяющуюся логику с хуками в отдельную функцию. Его имя должно начинаться с `use`, например `useFetch` или `useLocalStorage`.

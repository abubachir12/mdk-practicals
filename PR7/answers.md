# Ответы на вопросы к ПР7

1. Зачем связывать label и input через атрибут for?
Когда у label указан атрибут for, равный id инпута, клик по тексту надписи автоматически ставит курсор в поле ввода или переключает чекбокс. Это делает интерфейс удобнее, а скринридеры точно понимают, к какому именно полю относится подпись.

2. Как работает клиентская валидация в HTML5 без JavaScript?
HTML5 умеет проверять данные силами самого браузера через специальные атрибуты:
- required (не дает отправить пустую форму);
- type="email" или type="number" (проверяет корректность введенного формата);
- minlength / maxlength (ограничивает длину строки);
- pattern (проверяет ввод по регулярному выражению, например для телефона).

3. В чем разница между методами GET и POST?
- При методе GET данные формы прикрепляются прямо к URL-адресу (например, ?search=css). Он используется для поиска и фильтрации.
- При методе POST данные отправляются в скрытом теле HTTP-запроса. Он используется для отправки паролей, файлов и регистрации, чтобы не светить данные в адресной строке и истории браузера.

4. Для чего нужны псевдоклассы :valid и :invalid?
Они позволяют через CSS динамически подсвечивать рамку инпута зеленым или красным цветом в зависимости от того, правильно ли пользователь заполнил поле по правилам валидации.

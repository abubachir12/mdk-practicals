# Ответы на вопросы к ПР4

1. Что такое главная и поперечная оси во Flexbox?
Во Flexbox все строится вокруг двух осей. Главная ось (main axis) задается через свойство flex-direction: по умолчанию она идет горизонтально слева направо (row). Поперечная ось (cross axis) всегда идет строго перпендикулярно главной (по умолчанию сверху вниз). Если мы меняем flex-direction на column, оси меняются местами.

2. В чем разница между justify-content и align-items?
- justify-content управляет выравниванием элементов вдоль главной оси (например, центрирует их по горизонтали или раскидывает по краям через space-between).
- align-items выравнивает элементы вдоль поперечной оси (например, выравнивает их по высоте или центрирует по вертикали).

3. Зачем нужно свойство flex-wrap?
По умолчанию во флексе элементы стараются сжаться в одну строчку, даже если перестают помещаться. Свойство flex-wrap: wrap разрешает переносить элементы на новую строку, если ширины родительского контейнера больше не хватает.

4. Как работает запись flex: 1?
Это сокращение для трех параметров: flex-grow (жадность/растяжение), flex-shrink (сжатие) и flex-basis (базовый размер). Запись flex: 1 заставляет элементы равномерно поделить между собой все свободное пространство внутри родителя.

# Ответы на вопросы к ПР12

1. **preventDefault и stopPropagation.**  
`event.preventDefault()` отменяет стандартное действие браузера, например переход по ссылке. `event.stopPropagation()` останавливает распространение события по DOM.

2. **Как работает делегирование событий?**  
Один обработчик назначается родителю, а нужный дочерний элемент определяется через `event.target`. Это уменьшает число обработчиков и автоматически работает с динамически добавленными дочерними элементами.

3. **Фазы события.**  
Сначала идет capturing от корня к цели, затем target на целевом элементе, затем bubbling от цели обратно вверх. Параметр `capture` в `addEventListener` позволяет выбирать фазу.

4. **event.target и event.currentTarget.**  
`event.target` - элемент, на котором событие возникло. `event.currentTarget` - элемент, обработчик которого сейчас выполняется.

5. **Как создать CustomEvent?**  
Можно использовать `new CustomEvent("имя", { detail: данные })`, затем вызвать `dispatchEvent`. В `detail` можно передать нужные пользовательские данные.

6. **Debounce и throttle.**  
Debounce выполняет функцию после окончания серии частых событий. Throttle позволяет выполнять функцию не чаще заданного интервала. Debounce подходит для поля поиска, throttle - для scroll, resize и mousemove.

7. **Как удалять обработчики?**  
Используется `removeEventListener`, которому нужно передать ту же функцию и совместимые параметры. Также можно использовать `{ once: true }`, чтобы обработчик удалился после первого вызова. Удаление лишних обработчиков помогает избежать утечек памяти и неожиданных повторных действий.

8. **Как обрабатывать ошибки загрузки ресурсов?**  
Для изображений используются события `load` и `error`. Для скриптов также можно назначить обработчики `load` и `error`. В обработчике ошибки следует показать понятное сообщение или выполнить резервное действие.

9. **addEventListener и onclick.**  
`addEventListener` позволяет назначить несколько обработчиков одного события и управлять параметрами capture, once и passive. Свойство `onclick` хранит только один обработчик и новое присваивание заменяет старое.

10. **Как оптимизировать большое количество событий?**  
Использовать делегирование, debounce и throttle, удалять ненужные обработчики, применять passive listeners для подходящих scroll/touch событий, минимизировать тяжелые DOM-операции и не создавать большое число одинаковых обработчиков.

# Ответы на вопросы к ПР18

1. **Разница между Link и NavLink.** Оба компонента меняют адрес без перезагрузки страницы. `NavLink` дополнительно знает, активна ли ссылка: на текущей странице он добавляет класс `active` (или можно задать свой стиль через функцию в `className`). Поэтому `NavLink` используют для меню, а `Link` для обычных ссылок.

2. **Как получить параметры из URL?** Параметры пути описывают в маршруте через двоеточие, например `path="products/:id"`, а в компоненте получают хуком `useParams()`: `const { id } = useParams();`. Параметры строки запроса (`?category=books`) читают через `useSearchParams()`. Значения всегда приходят строками.

3. **Что такое программная навигация?** Это переход на другую страницу из кода, а не по клику на ссылку, например после отправки формы. Реализуется хуком `useNavigate`: `const navigate = useNavigate(); navigate('/contact/success');`. `navigate(-1)` возвращает на предыдущую страницу, а опция `{ replace: true }` заменяет текущую запись в истории.

4. **Как передать данные между маршрутами?** Небольшие данные можно передать через `state`: `navigate('/contact/success', { state: { formData } })`, а на новой странице прочитать через `useLocation().state`. Ещё варианты: параметры в адресе (`:id`, `?category=`), общий контекст (`useContext`) или внешнее хранилище. Данные из `state` пропадают, если открыть страницу напрямую, поэтому их нужно проверять.

5. **Что делает компонент Routes?** `Routes` просматривает все вложенные `Route` и отображает только тот, чей `path` лучше всего подходит под текущий адрес. Внутри него можно делать вложенные маршруты: в этой работе все страницы вложены в `Layout`, а меняющаяся часть выводится через `<Outlet />`.

6. **Как создать защищённый маршрут?** Нужно сделать компонент-обёртку, который проверяет, вошёл ли пользователь. Если нет, он возвращает `<Navigate to="/login" replace />`, иначе показывает дочерний компонент. В этой работе это `ProtectedRoute`: он защищает `/profile` и запоминает, куда хотел попасть пользователь, чтобы после входа вернуть его туда.

7. **Разница между useNavigate и redirect.** `useNavigate` это хук, его вызывают внутри компонента, обычно в обработчике события (клик, отправка формы). `redirect` это функция для загрузчиков и действий маршрутов (`loader` и `action` в data-роутерах React Router): она возвращает ответ с перенаправлением ещё до отрисовки компонента. Внутри разметки для перенаправления используют компонент `<Navigate />`.

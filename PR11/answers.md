# Ответы на вопросы к ПР11

1. **innerHTML и textContent.**  
`innerHTML` читает или вставляет HTML-разметку. `textContent` работает только с текстом и не интерпретирует теги. Для обычного пользовательского текста безопаснее использовать `textContent`.

2. **Как работает делегирование событий?**  
Обработчик назначается общему родителю, а нужный дочерний элемент определяется через `event.target` или `closest()`. Это удобно для динамически добавляемых элементов и уменьшает число обработчиков.

3. **Методы поиска элементов в DOM.**  
`getElementById` ищет один элемент по id. `querySelector` возвращает первый элемент по CSS-селектору. `querySelectorAll` возвращает все подходящие элементы в виде NodeList.

4. **Как предотвратить стандартное поведение?**  
Нужно вызвать `event.preventDefault()`. Это используется, например, чтобы отменить переход по ссылке или стандартную отправку формы.

5. **classList.add() и className.**  
`classList.add()` добавляет конкретный класс и не затрагивает остальные. Присваивание `className` заменяет всю строку классов элемента.

6. **Как создать и добавить элемент?**  
Можно использовать `document.createElement()` и `appendChild()`/`append()`, либо вставку HTML через `insertAdjacentHTML`. Для безопасного динамического контента обычно удобны `createElement` и `textContent`.

7. **Что такое всплытие событий?**  
После события на целевом элементе оно поднимается к его родителям. `stopPropagation()` останавливает дальнейшее распространение события.

8. **Как получить данные из формы?**  
Можно читать `.value` у отдельных полей, использовать `FormData(form)` или обращаться к элементам формы через `form.elements`. `FormData` особенно удобен для передачи набора полей.

9. **input, change и keyup.**  
`input` срабатывает при каждом изменении значения. `change` обычно срабатывает после завершения изменения и потери фокуса. `keyup` связан с отпусканием клавиши и не покрывает все способы изменения поля.

10. **Как оптимизировать частые DOM-операции?**  
Следует уменьшать число обращений к DOM, кэшировать найденные элементы, группировать изменения, использовать делегирование событий, `DocumentFragment`, а для частых событий - debounce или throttle.
